What is Ethereum? (a beginner's explainer)

Ethereum comes up almost as often as Bitcoin — but it's doing something a bit different. Here's the plain-English version.

In one line

A blockchain you can build apps on

Where Bitcoin is mainly digital money, Ethereum is a programmable platform. Its coin is ETH, and it runs "smart contracts" — programs that execute automatically.

Smart contracts

A smart contract is code on the blockchain that runs exactly as written, with no middleman. This is what powers a lot of crypto you hear about — DeFi, NFTs, and more. Powerful, but bugs in that code can be exploited.

"Gas" fees

Using the network costs a fee, paid in ETH, called gas. It rises when the network is busy and falls when it's quiet — which is why the same action can cost very different amounts at different times.

The beginner takeaway

Ethereum is more of a platform than just a coin. It's still volatile and experimental in places, so the same rules apply: learn first, secure your accounts, and only risk what you can afford to lose.
