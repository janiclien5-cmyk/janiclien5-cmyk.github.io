What is a DAO? (a beginner's explainer)

DAOs sound futuristic, but the core idea is just "a group run by code and votes instead of a boss." Here's the plain version — and the risks.

In one line

A community run by rules in code

A DAO (decentralized autonomous organization) is a group run by its members through rules written in smart contracts, rather than by a traditional company or boss. Members usually vote on decisions using tokens.

How it works

  • Rules and the treasury live on the blockchain, visible to all.
  • Members hold governance tokens that give them a vote.
  • Proposals are voted on, and approved actions can execute automatically.

What they're used for

Managing shared treasuries, running protocols, funding projects, or coordinating communities — anywhere a group wants transparent, member-driven control instead of a central authority.

The real risks

  • Code bugs: a flaw in the contracts can be exploited — funds can be lost.
  • Whale control: a few large token holders can dominate the "votes".
  • Experimental: many DAOs are early-stage and some fail.
