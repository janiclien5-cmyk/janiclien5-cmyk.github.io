What is a crypto token? (coin vs token)

"Coin" and "token" get used interchangeably, but they're not quite the same. Here's the simple difference — and why it's worth knowing.

The key difference

A coin has its own chain; a token is built on one

A coin runs on its own blockchain (like Bitcoin or Ether). A token is built on top of an existing blockchain using smart contracts, rather than having its own. All tokens are crypto — but not all crypto are coins.

The main kinds of tokens

  • Utility tokens: give access to a specific app or service.
  • Stablecoins: tokens designed to hold a steady value.
  • Governance tokens: a say in how a project is run.
  • NFTs: tokens representing a unique, one-of-a-kind item.

Why the difference matters

Because anyone can create a token on an existing chain quickly and cheaply, there are a lot of them — many low-quality or outright scams. So with tokens especially, researching the project behind it matters.
